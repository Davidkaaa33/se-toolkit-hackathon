Context

End User

CS2 players, casual-to-competitive gamers, who want to build a reliable team for Faceit matchmaking.

Problem

Solo queue matches players with random teammates who differ in skill, language, availability, or attitude — leading to frustrating matches.

The Product Idea

A web dashboard where CS2 players post profiles and discover compatible teammates by skill level, role, language, and playtime — connecting via Discord.

2 / 5

Implementation

How We Built It

  • Frontend: HTML/CSS/JavaScript with responsive design
  • Backend: Node.js + Express REST API
  • Database: PostgreSQL with session-based ownership
  • Deployment: Docker Compose (3 services)

Version 1 and Version 2

Version 1

  • Player profile via API
  • Filterable player directory
  • Session-based profile management

Version 2

  • Dockerized all services
  • Deployed to VM
